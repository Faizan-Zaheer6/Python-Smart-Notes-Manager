# 🗒️ Smart Notes Manager 🚀

A sleek, futuristic, and professional **Digital Notes Manager** built using Python and Streamlit. This app is designed with a **Glassmorphism UI** and provides essential features for daily productivity.

---

## ✨ Key Features

- **📝 Modern Note Taking:** Create and manage notes with titles, content, and tags.
- **🎨 Futuristic UI:** Custom CSS-driven interface with dark mode gradients and glass effects.
- **📥 Export as PDF:** Generate professional PDF reports of your notes instantly.
- **🔍 Quick Search:** Real-time filtering to find specific notes by title.
- **🛠️ Smart Actions:** Header-based actions to export data or clear your workspace.

---

## 🛠️ Tech Stack

- **Frontend:** [Streamlit](https://streamlit.io/) (Python Framework)
- **PDF Generation:** [FPDF](http://www.fpdf.org/)
- **Styling:** Custom CSS & Glassmorphism
- **Logic:** Python Lists & Session States
